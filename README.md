# Book Recommendation System

User-based collaborative filtering book recommender in Python using cosine similarity.

## Features

- User-book rating matrix
- Cosine similarity between users
- Finds the 3 most similar users and predicts ratings for unread books

## How to run

```bash
pip install numpy pandas scikit-learn
python book_recommendation.py
```
